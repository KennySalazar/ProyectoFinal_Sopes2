# Manual de usuario preliminar - version 0.1
1. Iniciar siguiendo README.md y abrir el frontend.
2. Seleccionar nivel de servicio y unidades; pulsar Crear pedido.
3. Observar estado, progreso y segundos restantes.
4. Crear mas de seis pedidos largos para producir espera.
5. Seleccionar PRIORIDAD (menor nivel primero), FIFO (orden de llegada), o
   UNIDADES (pedido mas corto primero). La politica solo afecta pedidos en espera.
6. Iniciar y detener generador. Se crea un pedido por segundo, sin cantidad final fija.
7. Consultar completados y promedios. Los promedios incluyen solo completados.
8. Al detener Java se pierde el historial: esta version trabaja en memoria.

No existen todavia cuentas, stock, recepciones, mapa de almacen ni panel de conflicto.
No usar este manual como documento de entrega final.
